<h1>Sistema de Controlo Financeiro em C </h1> 
<br>
Este repositório contém a resolução de uma atividade académica focada na criação de um sistema de controlo financeiro. Embora a proposta inicial previsse o uso da linguagem Python (sem recorrer a listas ou funções), optei por desenvolver a lógica inteiramente em C por iniciativa pessoal e foco no meu percurso de aprendizagem.

<h2> Contexto e Desenvolvimento </h2>
<br>

Sendo um projeto voltado para o estudo prático, encontrei algumas limitações naturais:
<br>
Restrições técnicas: Sem o uso de funções avançadas ou estruturas complexas, o código apoia-se em <strong> manipulações básicas de char e na reutilização de lógicas de projetos anteriores </strong>.

Recursos de apoio: O desenvolvimento contou com o <strong> auxílio de fóruns de programação, videoaulas, com destaque para as aulas sobre char do canal Eduardo Casavella no YouTube, e o livro C: Como Programar (dos irmãos Deitel) </strong>, que no terceiro capítulo aborda conceitos fundamentais de caracteres.

Uso de IA: <strong> A inteligência artificial Gemini foi consultada de forma pontual para debutar e ajustar estruturas lógicas </strong>. Por exemplo, o loop de validação de char utilizando for foi desenhado por mim, mas a ideia de o reestruturar para dois ciclos while foi debatida com a IA para evitar bugs e preservar a estabilidade do código.

Limitações Conhecidas e Próximos Passos:
<br>
Como o projeto reflete a minha evolução atual na programação, ainda apresenta algumas falhas humanas por corrigir. Um exemplo evidente ocorre no uso do scanf para valores do tipo float: se o utilizador introduzir caracteres em vez de números, o programa entra num ciclo infinito.

Este repositório serve como registo da minha evolução e persistência na resolução de problemas de forma autónoma!
